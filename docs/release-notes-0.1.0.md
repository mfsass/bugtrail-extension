# BugTrail 0.1.0 Pilot Release Notes

## Purpose

BugTrail 0.1.0 is a controlled QA pilot release for Chrome/Brave. It captures a QA reproduction trail and produces a developer-ready Markdown bug report.

## Release Artifacts

Generated by:

```powershell
$env:BUGTRAIL_BROWSER='C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe'
npm run verify:release
```

Artifacts:

- `.output/bugtrail-extension-0.1.0-chrome.zip`
- `.output/bugtrail-extension-0.1.0-chrome.zip.sha256`
- `.output/release-manifest.json`

Use `release-manifest.json` and the `.sha256` sidecar to verify the package hash before pilot distribution.

## Included Capabilities

- Chrome MV3 side-panel extension.
- Built-in access for Spur rewards admin production, stage, dev, localhost, and `127.0.0.1`.
- One-click `Add this site` flow for other internal QA apps.
- Click, route, input, select, submit, and bug-marker capture.
- API summary capture through `webRequest` and richer fetch/XHR page bridge evidence.
- Console error, warning, uncaught error, and unhandled rejection capture.
- App/environment inference from known Spur URLs, localhost, and common environment hostnames.
- Markdown report preview, copy, and `Save .md`.
- Redaction for common sensitive values in payloads, URLs, console output, field values, and report text.
- Bounded local evidence retention.
- Stale recording auto-stop after 8 hours.
- Shareable zip packaging with checksum metadata.

## Known Boundaries

- BugTrail is local-first and stores trail state in `chrome.storage.local`.
- `webRequest` cannot read response bodies; response summaries depend on the page-level fetch/XHR bridge.
- The pilot package is installed as an unpacked extension. It is not an `.exe`.
- Wider rollout should use private/unlisted Chrome Web Store publishing or Chrome Enterprise policy.
- Production signoff still requires authenticated Spur admin pilot evidence in `docs/live-pilot-checklist.md`.

## Rollback

For unpacked pilot installs:

1. Open `chrome://extensions` or `brave://extensions`.
2. Remove BugTrail or reload the previous extracted `chrome-mv3` folder.
3. Re-run the previous package through the same install steps.

For managed rollout, remove or replace the extension entry in the Chrome Enterprise policy.
